# TX-COMU Branding Standards

This repository follows the official **Texas Communications Unit (TX-COMU)** brand standards.

The canonical organization-wide brand guide is maintained in the TX-COMU `.github` repository:

https://github.com/Texas-Communications-Unit/.github/blob/main/brand/README.md

If this file conflicts with the canonical brand guide, the canonical guide controls.

## Organization identity

Use **Texas Communications Unit (TX-COMU)** on first formal reference. The abbreviation **TX-COMU** may be used afterward.

Official short description:

> Independent nonprofit supporting, connecting, and strengthening the Communications Unit community across Texas.

Do not use wording that implies TX-COMU is the State of Texas credentialing authority.

## Mission statement

The approved mission statement is:

> TX-COMU strengthens Texas’ emergency communications capabilities by developing skilled communicators, advancing interoperable systems, and serving communities with integrity, readiness, and technical excellence.

This language is controlled organizational messaging and should not be substantively rewritten without TX-COMU leadership approval.

## Brand character and voice

Project communications, documentation, user interface copy, presentations, screenshots, release notes, and public-facing materials should convey:

- Professionalism
- Credibility
- Readiness
- Stewardship
- Technical excellence
- Collaboration
- Service
- Resilience

Use clear, professional, accurate, welcoming, and mission-focused language. Prefer plain language where practical. Avoid exaggerated claims and unnecessary jargon.

## Approved digital colors

| Token | HEX | Primary use |
| --- | --- | --- |
| TX-COMU Navy | `#10233F` | Primary text, headers, dark surfaces |
| TX-COMU Blue | `#1F5F99` | Links, accents, interactive emphasis |
| TX-COMU Slate | `#465466` | Secondary text and metadata |
| TX-COMU Light | `#F4F7FB` | Light backgrounds and panels |
| White | `#FFFFFF` | Surfaces and reversed text |
| TX-COMU Red | `#D72638` | Limited emphasis and calls to attention |

Do not sample additional colors from the logo and reuse them as general-purpose interface colors.

## Typography

Use a clean, professional sans-serif typeface with strong readability. TX-COMU does not currently mandate one organization-wide font family.

For application UI and documentation:

- Prefer the native approved platform font stack.
- Maintain a logical heading hierarchy.
- Use one H1 per page/document where applicable.
- Maintain sufficient contrast consistent with WCAG 2.2 AA wherever practical.
- Do not introduce decorative fonts that reduce readability or conflict with the professional character of TX-COMU.

## Logo usage

Use only approved TX-COMU logo artwork from the canonical brand asset repository.

Do not:

- redraw, trace, or rebuild the logo;
- stretch or distort it;
- rotate it;
- crop it in a way that changes the approved composition;
- recolor it;
- outline it;
- add shadows, glows, or other effects;
- place it where surrounding graphics or low contrast reduce legibility;
- use it to imply official State of Texas status, endorsement, or credentialing authority.

Maintain the original proportions, transparent background, and adequate clear space.

## Photography and imagery

Prefer authentic TX-COMU photography showing real people, equipment, training, meetings, exercises, deployments, and partner activity when appropriate.

Do not publish imagery that exposes protected, private, or operationally sensitive information.

AI-assisted editing may be used for quality, lighting, cropping, or background consistency, but must not change identities, invent credentials, or create deceptive incident/deployment imagery.

## Software and UI requirements

All user-facing URPM work should follow the brand guide, including:

- desktop application UI;
- installer and splash screens;
- icons and branded assets;
- documentation;
- diagrams and architecture graphics;
- screenshots used in releases or documentation;
- GitHub issue and pull request templates;
- release notes;
- project website or future documentation site;
- presentations, PDFs, and training materials.

The product UI should use the approved digital palette consistently and should reserve TX-COMU Red for limited emphasis, warnings, errors, or calls to attention rather than routine decoration.

## Contributor requirement

Contributors are expected to review this file and the canonical brand guide before making user-facing changes.

Pull requests that add or modify UI, visual assets, public-facing text, screenshots, documentation, or branded materials should state whether the change has been checked against TX-COMU brand standards.

## Brand asset rights

The TX-COMU name, abbreviation, logos, and other identifying marks are organizational brand assets. Their presence in a public repository does not place them under the software project's license or authorize third parties to imply sponsorship, endorsement, affiliation, or credentialing authority.

For uses beyond accurate reference to TX-COMU, permission should be requested through https://tx-comu.org.
