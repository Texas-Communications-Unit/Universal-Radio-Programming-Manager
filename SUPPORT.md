# Support

URPM is under active development and is not yet a production radio-programming product.

## Questions and feature requests

Use GitHub Issues for:

- Feature proposals.
- Manufacturer/model support requests.
- Documentation improvements.
- Reproducible bugs using sanitized test data.
- Architecture and interoperability discussions.

## Do not use public issues for

- Encryption keys or key-management information.
- Agency credentials or protected system information.
- Real codeplugs containing sensitive data.
- Proprietary manufacturer software or restricted documentation.
- Security vulnerabilities that should be privately disclosed.

For security concerns, see [SECURITY.md](SECURITY.md).

## Manufacturer support

Manufacturer-specific functionality depends on available licenses, documentation, SDKs/APIs, supported programming interfaces, and formal authorization. Opening a support request does not imply that a particular radio can or will be directly programmed by URPM.
